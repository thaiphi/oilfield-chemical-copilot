## Current State and Gate

Completed baseline work: inventory; parsing and chunking; storage plus keyword and vector retrieval; source-grounded local Ollama RAG; hybrid RRF retrieval; public retrieval evaluation; public synthetic-answer evaluation; and the small public live vector-versus-hybrid baseline.

In the live baseline, both modes ran 12 questions with the same deterministic outcomes (citations: 4 pass/8 fail; abstention: 6 pass/6 fail) and all 12 judge results available per mode. The aggregates do not select a winner. They do not establish chemistry correctness or operational readiness.

The Module 4 public pack is a later, policy-enabled live measurement. On its six answerable cases, vector reached Hit Rate@5/MRR@5 `1.000/1.000`, while hybrid reached `1.000/0.917`; answer-boundary failures remained. The first sealed local run returned fixed status `unavailable` after one-shot state consumption and was not replayed. A fresh local v2 score then gave hybrid a meaningful retrieval advantage, but its citation and abstention failures prevent a production-mode decision.

The approved diagnosis reproduced the baseline: `vector` and `hybrid` each ran 12 questions and have category-identical results. Citation failures were allowed-retrieved-not-cited (1), mixed-with-disallowed (1), and unexpected-citation-when-abstention-expected (6); abstention failures were under-abstention (6). The aggregates do not select a winner or establish a retrieval cause.

The approved `claim_scope v1` shadow run reproduced the control baseline in both modes. Each mode used 12 paired questions and the same six allow/six abstain decisions. Control metrics were citation 4 pass/8 fail and abstention 6 pass/6 fail; shadow metrics were citation 10 pass/2 fail and abstention 12 pass/0 fail.

The claim-scope policy then passed a sealed, local 36-case v2 holdout with exact action and category matches, zero false allows, zero false abstains, and zero stratum failures. It now runs before retrieval in `BasicRagService`: abstained questions return a scope-limited response without retriever or generator calls, while allowed general-review questions use the unchanged RAG path.

The citation-selection branch then used an ID-only local diagnostic capture to distinguish retrieval from answer-path selection. For all six evidence-sufficient public cases, vector and hybrid each retrieved allowed evidence and cited allowed-only evidence. The deterministic selector now requires a question match to a source filename or declared topic before answer-content overlap can choose the source. The evaluator still bypasses the production claim-scope gate to preserve its historical overclaim baseline.

These are bounded safety, routing, and citation-structure results. They do not establish chemistry correctness, operational safety, private-corpus quality, a retrieval-mode winner, or production readiness.

The approved tool boundary is complete. It accepts only explicit product-ppm water-basis requests, calculates product gallons per day with the `42 gal/bbl` conversion, and applies the existing claim-scope gate before tool parsing. Closed requests invoke neither the calculator nor RAG; unrecognized requests follow the normal RAG path. This is an auditable general calculation, not a field-ready treatment recommendation.

The Module 1 monitoring boundary is complete, and the Module 5 implementation now extends it with privacy-safe hourly persistence and a local synthetic Grafana reviewer path. It is not hosted monitoring, alerting, production evidence, or a retention policy for raw application data.

The Module 7 reviewer package maps the course rubric to the committed public sample, code, tests, and aggregate reports. It preserves the measured-gap policy: hybrid RRF is available, while reranking and query rewriting remain excluded until a separate experiment identifies a retrieval problem they can address.

## Improvement Policy

Reranking is optional and metric-triggered. It is not supported by the current category-identical diagnosis and is not considered unless a separately approved investigation identifies a retrieval gap.
